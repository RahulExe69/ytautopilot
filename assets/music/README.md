# Background music

Put your licensed background tracks in this folder. You can add multiple tracks; the workflow automatically picks one per Short so there is no manual selection.

Supported formats: MP3, WAV, M4A, AAC, and OGG.

Keep your audio filenames as uploaded; the renderer scans this folder for supported audio files and selects one automatically. Gameplay audio is muted completely; only the selected background track is mixed quietly beneath the narrator.

Only use music that you own or are licensed/authorized to reuse.
